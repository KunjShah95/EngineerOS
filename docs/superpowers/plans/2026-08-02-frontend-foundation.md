# Frontend Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build step 1 of the Phase 6 frontend MVP — a working Next.js scaffold with the EngineerOS design-token system, theme toggle, and authenticated app shell with route stubs. No Supabase (deferred to step 2).

**Architecture:** Next.js App Router with route groups: `(marketing)` for landing, `(auth)` for login/register, `(app)` wrapped in a shared shell layout (left nav + top bar). Theme is a Zustand store persisted to `localStorage` (`engineeros-theme` key), applied via `data-theme` on `<html>`; a `beforeInteractive` inline script prevents a flash of the wrong theme on reload. Tailwind v4 maps DESIGN_SYSTEM.md CSS variables to utilities via `@theme inline`; dark is `:root`, light is `[data-theme="light"]`.

**Tech Stack:** Next.js (App Router, TypeScript, ESLint, src dir), Tailwind CSS v4, shadcn/ui (Button, Separator), Zustand, Lucide icons, next/font (Inter + JetBrains Mono).

**Build order note:** Steps use verification via `npm run build`, `npm run lint`, and `npm run dev` + manual browser checks. No unit-test framework is added — the docs specify none for step 1 and the work is configuration/static UI; acceptance criteria from UI_DEVELOPMENT_PLAN.md are checked manually. This plan does NOT pull forward Supabase, auth logic, Quick Capture, or command palette — those are later steps.

- [ ] **Step 1: Create the Zustand theme store**

`src/lib/store/theme.ts`:

```ts
import { create } from 'zustand';

export type Theme = 'dark' | 'light';

export const THEME_STORAGE_KEY = 'engineeros-theme';

interface ThemeState {
  theme: Theme;
  setTheme: (theme: Theme) => void;
}

export const useThemeStore = create<ThemeState>()((set) => ({
  theme: 'dark',
  setTheme: (theme) => set({ theme }),
}));

export function getStoredTheme(): Theme {
  if (typeof window === 'undefined') return 'dark';
  try {
    return window.localStorage.getItem(THEME_STORAGE_KEY) === 'light' ? 'light' : 'dark';
  } catch {
    return 'dark';
  }
}
```

- [ ] **Step 2: Create the ThemeProvider**

`src/components/theme/ThemeProvider.tsx`:

```tsx
'use client';

import { useEffect } from 'react';
import { getStoredTheme, THEME_STORAGE_KEY, useThemeStore } from '@/lib/store/theme';

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const theme = useThemeStore((s) => s.theme);
  const setTheme = useThemeStore((s) => s.setTheme);

  useEffect(() => {
    setTheme(getStoredTheme());
  }, [setTheme]);

  useEffect(() => {
    document.documentElement.dataset.theme = theme;
    try {
      window.localStorage.setItem(THEME_STORAGE_KEY, theme);
    } catch {
      // ignore storage errors (private mode / disabled cookies)
    }
  }, [theme]);

  return <>{children}</>;
}
```
