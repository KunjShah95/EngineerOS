# VISION.md — EngineerOS

## Product Vision

EngineerOS is an AI-native operating system for engineers, researchers, and builders. It unifies notes, tasks, projects, research, learning, GitHub context, papers, architecture docs, and daily journaling into one connected system — not a CRUD notes app, but the foundation for an AI memory layer.

Mental model: **Obsidian + Linear + Notion + NotebookLM + Cursor Memories + AI Agent**, in one workspace.

## Problem Statement

Current engineer workflow is fragmented across:

- Google Docs
- Notion
- GitHub
- Excalidraw
- Obsidian
- Calendar
- Sticky notes
- ChatGPT / Claude threads
- PDFs
- Bookmarks

Context lives in ten places at once. Nothing links back to anything else. Nothing remembers what you did last week without you going and finding it.

EngineerOS unifies capture, organization, and retrieval into a single connected system, laying groundwork for an AI layer that can eventually reason over all of it.

## Target Users

**Secondary**

- Agencies

## Long-Term Direction

V1 (this build) is deliberately non-AI: capture, find, organize. It exists to produce clean, connected, well-structured data — projects, tasks, notes, daily notes — so that later phases (AI Layer, Knowledge Graph, Automation) have something real to reason over instead of a blank database.

Every schema and IA decision in Phase 1–7 should be made with Phases 8–10 in mind (AI layer, knowledge graph, automation), without pulling any of that work forward.
